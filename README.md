# 🧰 Pom-Chan Focus Studio

A cutesy desktop customization focus engine and companion web-app. Designed with a visual-novel style aesthetic to help you stay productive, lock in deep focus blocks, and customize your study environment.

## 🚀 Live Demo

https://nickquinn2036.github.io/pom-chan/

## 🎭 Features

- **Fluid Customization Sidebar:** Slide out the control panel to customize your studio.
- **Triple-Slot Expression Studio:** Set distinct visual avatars or sprites for **Study**, **Standby**, and **Break** states. Supports both direct web URLs and local file uploads.
- **Dialogue Configuration:** Add your own motivational strings to custom dialogue pools, assign custom nametags, or toggle "Custom Lines Only."
- **Room Background Studio:** Upload local backdrops or paste web links to swap out your wallpaper environment seamlessly.
- **Interactive Timer Clock:** Click and type directly into the countdown clock with built-in number masks and error validation.
- **Fluid Drag-and-Drop:** Move the entire interface dynamically around your viewport window.
- **LocalStorage Anti-Crash Engine:** Automatically remembers your text strings, custom names, and settings across browser refreshes without exceeding browser storage limits.
